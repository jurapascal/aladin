Aladin

Pracovní prostředí pro tým (dříve Claude Code Hub): každý člen má na serveru test.alba-rosa.cz vlastní izolovaný prostor, ve kterém pracuje s asistentem Claude Code — s projekty, poznámkami a službami, které si sám napojí.

Co aplikace dělá

  • Přihlášení do prostoru mají jen pozvaní členové týmu; účty zakládá správce.
  • V prostoru běží Claude Code a jeho terminál, soukromá paměť a projekty uživatele.
  • Uživatel si může napojit vlastní účty služeb — Freelo, Canva, Ecomail a Google (Gmail, Disk, Kalendář, Dokumenty, Tabulky, Prezentace, Formuláře, Úkoly, Kontakty). Claude s nimi pracuje jen tehdy, když ho o to uživatel sám požádá.
  • Napojení jsou soukromá: jiní uživatelé k nim ani k datům z nich nemají přístup.

In English

Aladin (formerly Claude Code Hub) is an internal workspace for a small team. Each invited member gets an isolated workspace on test.alba-rosa.cz running the Claude Code assistant, and may connect their own Google, Freelo, Canva and Ecomail accounts. Data is used only for tasks the user requests. See the privacy policy.
