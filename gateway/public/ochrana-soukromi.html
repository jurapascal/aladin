O jakou aplikaci jde

Aladin (dříve Claude Code Hub) je interní pracovní prostředí pro tým na serveru test.alba-rosa.cz. Každý pozvaný člen má vlastní izolovaný prostor, ve kterém pracuje s asistentem Claude Code. Více v popisu aplikace.

Jaká data z účtu Google aplikace získává

Jen tehdy, když uživatel sám napojí svůj účet Google a na přihlašovací obrazovce Googlu výslovně souhlasí. Aplikace pak smí v rozsahu potvrzených oprávnění pracovat s jeho Gmailem, Diskem, Kalendářem, Dokumenty, Tabulkami, Prezentacemi, Formuláři, Úkoly a Kontakty, a zná e-mailovou adresu a jméno účtu, aby napojené účty rozlišila.

K čemu se data používají

  • Výhradně k úkolům, které uživatel sám zadá asistentovi Claude Code ve svém prostoru — například „najdi e-mail od…“ nebo „přidej schůzku do kalendáře“.
  • Data neprodáváme, nepředáváme k reklamě, nepoužíváme k profilování a nepoužíváme je k vývoji ani trénování obecných modelů umělé inteligence.
  • Obsah, se kterým má Claude na pokyn uživatele pracovat, se posílá ke zpracování službě Claude společnosti Anthropic, která asistenta provozuje. Jiným třetím stranám se data nepředávají.

Kde a jak dlouho jsou data uložená

  • Přístupové tokeny k účtu Google jsou uložené jen v izolovaném prostoru uživatele na serveru; jiní uživatelé k nim přístup nemají.
  • Obsah z účtu Google (e-maily, soubory, události) se ukládá jen tehdy, když o to uživatel výslovně požádá — jinak se čte jen pro daný úkol.
  • Tokeny i uložené údaje zůstávají, dokud uživatel účet neodpojí nebo dokud není jeho prostor zrušen.

Jak přístup zrušit a data smazat

  • V aplikaci: Nastavení → Napojení → Google → u účtu tlačítko ×. Tím se token v prostoru smaže.
  • V účtu Google: myaccount.google.com/permissions → Aladin (případně Claude Code Hub) → Odebrat přístup.
  • Smazání celého prostoru i s uloženými údaji: napište na kontakt níže.

Summary in English

Aladin (formerly Claude Code Hub) accesses a user's Google data (Gmail, Drive, Calendar, Docs, Sheets, Slides, Forms, Tasks, Contacts) only after the user connects their account and consents. The data is used solely to perform tasks the user asks the Claude Code assistant to do in their own workspace; content needed for such a task is processed by Anthropic's Claude service. We do not sell data, use it for advertising, or use it to train general AI models. OAuth tokens are stored only in the user's isolated workspace. Users can disconnect in Settings → Connections or at myaccount.google.com/permissions. Aladin's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Contact: boucnik.jiri@gmail.com.
